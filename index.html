02El producto

Una solución contable integral, offline y a un clic de distancia

El Simulador Contable SurTech es una aplicación de escritorio desarrollada en Windows Forms con base de datos SQLite que automatiza el ciclo contable completo: del comprobante al balance.

Cada compra y cada venta registrada dispara una cadena de procesos automáticos: el inventario se valúa por PEPS (primero entrado, primero salido), el IVA se liquida en tiempo real, los asientos se generan solos en el Libro Diario y el sistema controla los vencimientos de cobros y pagos.

Es una solución integral pensada para la gestión contable y académica: ideal para cátedras de Administración y Contabilidad que necesitan simular la realidad operativa de una empresa — sin depender de planillas frágiles ni conexiones a internet.

  • Windows Forms
  • SQLite embebido
  • Visor PDF integrado
  • Motor de reglas contables
  • 100% offline

Libro Diario automatizado

Los asientos se generan automáticamente con cada operación, con contrapartidas balanceadas y trazabilidad completa.

Inventario PEPS

Valuación de existencias por primer entrado, primer salido: costo real y trazabilidad por lote en cada salida.

Liquidación de IVA

Débito y crédito fiscal calculados en tiempo real, con la posición del período siempre actualizada.

Control de vencimientos

Cuotas, cobros y pagos monitoreados con alertas anticipadas para que nada se venza sin aviso.
