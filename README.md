# SurTech · Simulador Contable SurTech V2.1

Sitio web corporativo e institucional de **SurTech** y su producto principal, el
**Simulador Contable SurTech V2.1**: innovación y control financiero offline para
la gestión contable y académica.

**Ver el sitio:** <https://strombergleonardo.github.io/surtech-web/>

## Secciones

- **Hero** — presentación del producto con CTAs "Ver Módulos" y "Solicitar Presentación"
- **Cifras clave** — contadores animados del producto
- **01 · ¿Quiénes Somos?** — SurTech y sus valores
- **02 · El Producto** — solución Windows Forms + SQLite y el efecto dominó contable
- **03 · Módulos del Sistema** — 5 tarjetas interactivas con funcionalidades
- **04 · Comparativa vs. Excel** — tabla de ventajas
- **Footer institucional** — cátedra, contacto y aviso legal

## Tecnología

HTML, CSS y JavaScript puro, sin frameworks ni dependencias. Tipografía Inter
(Google Fonts con fallback del sistema). Diseño responsive (móvil, tablet y PC)
con paleta de marca: pizarra `#0F172A`, naranja SurTech `#F97316` y azul
tecnológico `#0EA5E9`.

## Desarrollo local

Abrir `index.html` en cualquier navegador — no requiere servidor ni instalación.
